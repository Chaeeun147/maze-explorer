Maze Explorer is a 2D platformer game starring Cappy, a capydara! Explore rooms, collect treasures (turtle shells), avoid enemies (jaguars), and reach the exit to go to the next level!
<img width="1263" height="706" alt="image" src="https://github.com/user-attachments/assets/140fe509-9203-4822-a229-3e7c14f549f8" />



Controls:

- W, Up Arrow, Space = JUMP
- A, Left Arrow = BACKWARD
- D, Right Arrow = FORWARD


How to Run Locally:

Itch link: https://chey17.itch.io/maze-explorer


Tech Stack:

- Languages: GD Script
- Framework: Godot Engine
- Tools: Piskel (pixel art creation)
